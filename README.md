# 见微知乡

[打开公开演示站](https://jianwei-village-weekends.qizhiyuan1919.chatgpt.site)

一套可独立运行的文旅网站交互演示，包含目的地发现、目的地详情、行程助手、旅行广场和我的旅行。界面适配桌面与手机。

## 运行方式

- 项目版：打开 docs/index.html。保留 docs/assets 文件夹与网页的相对位置。
- 本地服务：在 docs 文件夹启动任意静态 HTTP 服务，然后打开对应地址。

## 已实现的交互

- 8 处目的地的关键词、省市、车程、玩法联合筛选，情境快捷选择，综合与距离排序，空结果状态。
- 目的地详情、六项出行事实、步行路线、在地介绍、限制提醒和替代方案。
- 中文旅行条件识别、单项澄清、条件表单、1 至 3 天演示规划、交通与预算分项、更换体验、雨天模式、单独修改第二天、保存及历史编辑。
- 广场身份筛选、点赞、收藏、评论、游记详情、行程复制与来源署名、本地内容预览与发布。
- 收藏目的地、保存规划、我的故事、收藏的故事、手动足迹、偏好设置、删除确认与 JSON 数据导出。
- 浏览器前进后退、键盘焦点、Esc 关闭弹窗、弹窗焦点约束、图片失败替代与减少动效设置。

## 数据与服务边界

规划由本地样例数据和确定性规则生成，没有调用真实模型、实时天气、地图、营业状态、支付或预订接口。地名是真实名称；活动、路线、时间、费用和故事为演示资料，出发前须独立核实。待核实字段不会自动补成确定的事实。

收藏、规划、点赞、评论、发布内容、足迹和偏好通过 localStorage 保存在当前浏览器。在线站点与本地文件属于不同来源，数据各自保存，不会同步。隐私模式或浏览器策略可能限制本地文件的存储；遇到这种情况建议使用在线版或本地 HTTP 服务。清理浏览器数据会移除这些记录。

## 源码结构

- src/index.html：页面容器
- src/styles.css：视觉规范与响应式布局
- src/data.js：目的地、游记与摄影信息
- src/app.js：路由、状态、交互与规划规则
- build.py：使用 Python 标准库将源码合并为 docs/index.html
- docs/assets：已优化的摄影文件及许可信息

源码修改后运行 python build.py。项目不依赖 npm 包和构建框架。

## GitHub Pages

发布目录为 `main` 分支的 `/docs`。修改源码后运行 `python build.py`，然后一并提交源码和生成的 `docs/index.html`。
